# 拼贴文字工具 - Product Requirements Document

## Overview
- **Summary**: 一个中英文文字拼贴生成器，用户输入文字后生成"手撕纸拼贴"风格的图片，用于电子手帐、社交分享。面向手机端用户为主。
- **Purpose**: 提供简单易用的文字转拼贴图片工具，让用户无需设计技能即可生成有质感的拼贴文字图。
- **Target Users**: 电子手帐爱好者、社交分享内容创作者、需要快速生成文字配图的用户。

## Goals
- 用户输入文字即可一键生成拼贴风格图片
- 生成结果可复现（种子机制）
- 移动端优先，单手可操作
- 字体、配色、背景均可扩展

## Non-Goals
- 不做中文自动分词（逐词模式下由用户手动用空格分组）
- 不允许用户自选颜色（使用内置色板）
- 不做单个纸片的独立调节（大小/颜色/位置均由系统按规则生成）
- 不做在线字体编辑器
- 第一版不包含社交分享直接发布功能（仅导出图片）

## Background & Context
- 项目从零开始，工作目录为空
- 技术选型：纯前端 Web 应用（HTML + CSS + JavaScript），使用 Canvas API 进行渲染
- 参考设计风格：ArchDaily 网站的白底极简、杂志式网格、蓝色点缀
- 字体需商用免费，先内嵌起步，后续可扩展

## Functional Requirements

### 输入与分词
- **FR-1**: 提供单一文本输入框，支持中英文、数字、标点混输
- **FR-2**: 提供三档成片单位选择：逐字、混合（默认）、逐词
  - 逐字：每个字符单独成片（英文也逐字母）
  - 混合：中文逐字 + 英文/数字按词成片
  - 逐词：中文按空格手动分组成片
- **FR-3**: 分词在渲染前生效，同一输入框同一输出

### 纸片与排版
- **FR-4**: 纸片按字形轮廓分四类：方形、平行四边形、梯形、不规则
- **FR-5**: 纸片边缘模拟手撕效果（抖动边缘）
- **FR-6**: 文字必须完整落在纸片内，任何情况不允许溢出
- **FR-7**: 错落感来源：旋转、上下浮动、颜色字号差异、手撕边缘
- **FR-8**: 随机幅度拉条（0–100%）：0 完全整齐，100% 最大随机
  - 只控制摆放类随机：旋转上限约 ±12°、上下浮动上限约 ±0.4 字符高度
  - 颜色/字体/字号随机为独立开关
- **FR-8a**: 全局字号缩放：用户可统一调节所有拼贴单位（文字和纸片一起）的大小，整个文本一起缩放，非单个调节
- **FR-8b**: 对齐方式四选一：左对齐、右对齐、居中对齐、首行缩进（缩进两个拼贴单位宽度）
- **FR-8c**: 长文本自动换行：当内容超出画布有效宽度时自动换行
  - 换行规则：避免行首出现标点（中文标点不留在行首）
  - 换行规则：避免拆分英文单词（英文单词整体换行）

### 字体
- **FR-9**: 内嵌至少 2 个商用免费中文字体（400/700 字重）
- **FR-10**: 字体采用可扩展机制：字体列表/文件夹独立管理，支持后续添加

### 种子机制
- **FR-11**: 所有随机决策由种子驱动：同文本 + 同种子 + 同参数 = 同图
- **FR-12**: 改部分文字 + 同种子：未改位置样式保持不变，只重排变化的字符
- **FR-13**: 样式按位置分配（非按字符内容）
- **FR-14**: 纸片轮廓基于当前实际字形实时生成；种子只传承手撕风格参数
- **FR-15**: 下载图片的文件名包含种子号

### 配色
- **FR-16**: 用户不可自选颜色
- **FR-17**: 内置 4–6 套手帐向色板：复古奶油、莫兰迪灰粉、牛皮纸暖褐、朱砂红配墨蓝、低饱和糖果、黑白灰极简
- **FR-18**: 每张图先随机定套，填充色与描边色都在同一套内取
- **FR-19**: 描边默认取该套固定深色锚点（每套 1–2 个）；约 10% 概率描边同套内任取
- **FR-20**: 随机幅度拉条高时，允许颜色在色板附近小范围漂移
- **FR-21**: 色板以独立配置文件组织，先内置占位色板

### 输出尺寸与背景
- **FR-22**: 提供尺寸和背景两个独立选项
- **FR-23**: 尺寸三档：正方形 1:1 (2048×2048)、3:4 竖版 (1080×1440)、手机壁纸 (1290×2796)
- **FR-24**: 背景五档：笔记本纸、白纸、点线纸、牛皮纸、透明 PNG
- **FR-25**: 带背景的导出：背景铺满整个画布，内容在有效区内排版
- **FR-26**: 透明 PNG：固定画布 + 四周约 8% 透明出血
- **FR-27**: 纸纹素材框架先搭好，留出素材文件夹，先用占位文件

### 页面与交互
- **FR-28**: 页面风格参考 ArchDaily：白底极简、大量留白、杂志式网格、无衬线细字体
- **FR-29**: 蓝色点缀，取 ArchDaily logo 蓝色同色号
- **FR-30**: 移动端优先：单手可操作、触控友好、竖屏布局，桌面端适配补全
- **FR-31**: 提供实时预览功能
- **FR-32**: 提供重新生成（换种子）功能
- **FR-33**: 提供下载导出功能
- **FR-34**: 提供全局字号缩放控件（文字和纸片一起缩放）
- **FR-35**: 提供对齐方式选择（左对齐/右对齐/居中/首行缩进）

## Non-Functional Requirements
- **NFR-1**: 移动端优先，竖屏布局，触控目标 ≥ 44px
- **NFR-2**: 页面加载时间 < 3s（含字体加载）
- **NFR-3**: 生成图片响应时间 < 2s（常规输入，< 50 字符）；长文本（≤ 500 字符）< 5s
- **NFR-4**: 导出图片质量：JPG 质量 ≥ 90%，PNG 无损
- **NFR-5**: 兼容主流移动端浏览器（iOS Safari、Chrome Android）及桌面端 Chrome
- **NFR-6**: 所有随机可复现（种子机制）
- **NFR-7**: 代码模块化，字体/色板/背景素材独立管理，便于扩展

## Constraints
- **Technical**: 纯前端实现，无后端依赖；使用 Canvas API 渲染；字体需内嵌或 CDN 加载
- **Business**: 字体必须商用免费；不收集用户数据
- **Dependencies**: 需确认 ArchDayly logo 蓝色色值；需获取商用免费中文字体文件

## Assumptions
- 用户设备支持 Canvas API
- 用户在现代浏览器中使用（ES6+）
- 字体文件可以内嵌或通过 CDN 加载
- 纸纹素材先用 CSS/Canvas 程序化生成或占位图代替

## Acceptance Criteria

### AC-1: 文本输入与分词
- **Type**: `rule`
- **Given**: 用户在输入框中输入文字
- **When**: 选择不同的成片单位（逐字/混合/逐词）
- **Then**: 文字被正确分割为对应的成片单位
- **Pass Condition**: 逐字模式每个字符单独成片；混合模式中文逐字、英文数字按词；逐词模式按空格分组
- **Evidence**: 输入测试文本，验证分词结果正确

### AC-2: 纸片形状多样性
- **Type**: `rule`
- **Given**: 生成拼贴图片
- **When**: 查看生成结果
- **Then**: 纸片呈现方形、平行四边形、梯形、不规则四种形状
- **Pass Condition**: 多次生成后能观察到四种形状均出现
- **Evidence**: 生成多张图片，检查纸片形状类型覆盖

### AC-3: 文字不溢出纸片
- **Type**: `rule`
- **Given**: 任意输入文字
- **When**: 生成拼贴图片
- **Then**: 所有文字完整落在对应纸片内，无溢出
- **Pass Condition**: 放大检查每张纸片，文字边缘与纸片边缘有安全间距，无任何字符超出纸片边界
- **Evidence**: 生成包含中英文、长词、大字号的测试图，逐纸片检查

### AC-4: 手撕纸边缘效果
- **Type**: `rubric`
- **Dimension**: 纸片边缘手撕质感的视觉还原度
- **Scale**: 1-5
- **Anchors**: 1 = 边缘完全平直无手撕感; 3 = 有轻微抖动但不够自然; 5 = 边缘抖动自然，有明显手撕纸质感
- **Pass Threshold**: >= 4
- **Evidence**: 视觉检查生成图片的纸片边缘

### AC-5: 随机幅度控制
- **Type**: `rule`
- **Given**: 随机幅度拉条
- **When**: 拉条设为 0%
- **Then**: 所有纸片完全整齐排列，无旋转、无浮动
- **Pass Condition**: 拉条 0% 时所有纸片对齐、无旋转角度、无上下偏移
- **Evidence**: 设置拉条为 0，检查输出图片

### AC-6: 随机幅度控制（最大）
- **Type**: `rule`
- **Given**: 随机幅度拉条
- **When**: 拉条设为 100%
- **Then**: 旋转和浮动达到最大幅度
- **Pass Condition**: 旋转角度在 ±12° 范围内随机分布，浮动在 ±0.4 字符高度范围内
- **Evidence**: 设置拉条为 100，测量多张纸片的旋转角度和偏移量

### AC-7: 种子复现性
- **Type**: `rule`
- **Given**: 相同文本、相同种子、相同参数
- **When**: 两次生成图片
- **Then**: 两次生成结果完全一致
- **Pass Condition**: 生成的两张图片像素级一致（或关键参数完全一致）
- **Evidence**: 记录种子号，同参数生成两次，对比结果

### AC-8: 种子局部修改
- **Type**: `rule`
- **Given**: 文本 A 生成图片后
- **When**: 修改文本 A 中的部分字符，保持同一种子
- **Then**: 未修改位置的样式保持不变，仅变化的字符重新排版
- **Pass Condition**: 未修改位置的纸片形状、颜色、旋转角度与原图一致
- **Evidence**: 修改文本后对比，检查未变位置的样式

### AC-9: 色板系统
- **Type**: `rule`
- **Given**: 生成拼贴图片
- **When**: 多次生成
- **Then**: 使用内置色板，填充色和描边色来自同一套色板
- **Pass Condition**: 每张图的所有纸片颜色来自同一色板，不出现混搭
- **Evidence**: 检查生成图片的颜色来源

### AC-10: 输出尺寸
- **Type**: `rule`
- **Given**: 选择不同尺寸选项
- **When**: 导出图片
- **Then**: 图片尺寸符合选项规格
- **Pass Condition**: 正方形 2048×2048、3:4 为 1080×1440、壁纸为 1290×2796
- **Evidence**: 导出后检查图片尺寸属性

### AC-11: 透明 PNG 出血
- **Type**: `rule`
- **Given**: 选择透明 PNG 背景
- **When**: 导出图片
- **Then**: 四周有约 8% 透明出血区域
- **Pass Condition**: 正方形出血约 164px/边，3:4 约 86px/边
- **Evidence**: 检查导出 PNG 的透明区域

### AC-12: 移动端适配
- **Type**: `rubric`
- **Dimension**: 移动端单手操作友好度
- **Scale**: 1-5
- **Anchors**: 1 = 布局混乱，无法在手机上正常使用; 3 = 基本可用但部分操作不便; 5 = 竖屏布局合理，触控目标足够大，单手操作流畅
- **Pass Threshold**: >= 4
- **Evidence**: 在手机视口（375×812）下检查布局和交互

### AC-13: 页面设计风格
- **Type**: `rubric`
- **Dimension**: 页面视觉风格与 ArchDaily 参考的契合度
- **Scale**: 1-5
- **Anchors**: 1 = 风格完全不符; 3 = 有部分相似元素但整体差距大; 5 = 白底极简、留白充足、网格感强、蓝色点缀到位
- **Pass Threshold**: >= 4
- **Evidence**: 视觉对比检查

### AC-14: 导出文件名含种子号
- **Type**: `rule`
- **Given**: 生成并下载图片
- **When**: 查看下载的文件名
- **Then**: 文件名包含当前种子号
- **Pass Condition**: 文件名格式中包含种子数字
- **Evidence**: 下载图片后检查文件名

### AC-15: 字体可扩展
- **Type**: `rule`
- **Given**: 字体配置目录
- **When**: 添加新字体文件并更新配置
- **Then**: 新字体在应用中可用
- **Pass Condition**: 字体列表独立管理，添加字体只需放入文件并更新配置
- **Evidence**: 检查字体管理的代码结构

### AC-16: 色板可扩展
- **Type**: `rule`
- **Given**: 色板配置目录
- **When**: 添加新色板配置
- **Then**: 新色板在生成中可用
- **Pass Condition**: 色板以独立配置文件组织，可直接添加新文件
- **Evidence**: 检查色板管理的代码结构

### AC-17: 背景素材可扩展
- **Type**: `rule`
- **Given**: 背景素材目录
- **When**: 替换或添加纸纹素材
- **Then**: 新背景在选项中可用
- **Pass Condition**: 背景素材独立目录管理，占位文件可直接替换
- **Evidence**: 检查背景素材的目录结构

### AC-18: 全局字号缩放
- **Type**: `rule`
- **Given**: 全局字号缩放控件
- **When**: 调节缩放值
- **Then**: 所有拼贴单位的文字和纸片同步放大或缩小
- **Pass Condition**: 缩放后文字与纸片比例不变，整体变大或变小，无单个纸片独立变化
- **Evidence**: 调节缩放前后对比，检查文字和纸片同步变化

### AC-19: 长文本自动换行
- **Type**: `rule`
- **Given**: 输入超过单行宽度的长文本
- **When**: 生成拼贴图片
- **Then**: 文本自动换行以适应画布宽度
- **Pass Condition**: 内容不超出画布有效区域，自动分成多行
- **Evidence**: 输入约 200 字文本，检查换行结果

### AC-20: 换行不拆英文单词
- **Type**: `rule`
- **Given**: 输入包含英文单词的长文本
- **When**: 英文单词恰好在行尾边界
- **Then**: 整个英文单词移到下一行，不被拆分
- **Pass Condition**: 任何英文单词完整出现在同一行，不跨行拆分
- **Evidence**: 输入含长英文单词的文本，检查无单词跨行

### AC-21: 换行避免行首标点
- **Type**: `rule`
- **Given**: 输入含中文标点的文本
- **When**: 标点恰好在换行位置
- **Then**: 标点不留在下一行行首
- **Pass Condition**: 中文标点（。，、；：！？等）不出现在行首位置
- **Evidence**: 输入含标点的文本，检查行首无标点

### AC-22: 对齐方式
- **Type**: `rule`
- **Given**: 对齐方式选择控件
- **When**: 选择左对齐/右对齐/居中/首行缩进
- **Then**: 多行文本按所选方式对齐
- **Pass Condition**: 左对齐各行左边缘对齐；右对齐各行右边缘对齐；居中各行居中；首行缩进第一行缩进两个单位宽度
- **Evidence**: 分别选择四种对齐方式，检查对齐效果
